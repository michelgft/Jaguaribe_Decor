# Jaguaribe Decor

## IFPB-CSTSI / Projeto PW2
### Desenvolvimento de aplicação web completa para uma loja de decoração

#### Tecnologias Atualizadas
- Next.js 14 - Framework React com App Router
- React 18 - Biblioteca para interfaces modernas
- JavaScript ES6+ - Linguagem principal do projeto
- Tailwind CSS - Estilização utilitária e responsiva
- Supabase - Backend completo (Banco de dados, Autenticação, Storage)
- PostgreSQL - Banco de dados relacional
- Vercel - Hospedagem e deploy automático

#### Funcionalidades Principais
- Catálogo de produtos com filtros por categorias
- Carrinho de compras em tempo real
- Autenticação de usuários (Login/Cadastro)
- Gestão de clientes integrada ao Supabase
- Dashboard administrativo (se aplicável)
- Sistema de pedidos completo
- Upload de imagens para produtos
- Design responsivo para todos os dispositivos
